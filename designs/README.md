# Thiết kế giao diện

Bản mẫu giao diện (artifact): https://claude.ai/artifact/WN3Ci9Zc1WEA6VzidrdHRj

Thư mục `artifact-giao-dien/` là mã nguồn các màn của artifact đó (định dạng Design canvas):

| File | Màn hình |
|---|---|
| `Main.dc.html` | Sảnh · Tạo phòng (nhập base 1–1000, tuỳ chọn ăn cây, thời gian lượt) |
| `Room.dc.html` | Phòng chờ (4 ghế, chọn người đánh sau chủ phòng) |
| `Table.dc.html` | Bàn chơi trên chiếu: 4 góc, nọc giữa, bài đánh trên cạnh khung, hạ bài, Ù, tạm dừng, hết giờ |
| `Scoreboard.dc.html` | Bảng điểm phòng · Lịch sử trận |
| `canvas.json` | Bố cục các màn trên canvas |

Khổ thiết kế: iPhone 15 Pro Max xoay ngang (932 × 430 pt). Yêu cầu chi tiết: mục 12 của
`docs/luat-choi-ta-la.md`.
